# Application email

D274 DEFAULT implements the existing Keycloak design's MailerSend choice for .NET application email. Authentication and sign-in links remain Keycloak-owned. This adapter does not send Keycloak verification/sign-in email or mint sessions.

API and operator commands share `ApplicationEmailSetup`. `Email:Provider=mailersend` explicitly enables the actual HTTP adapter. Missing/invalid enabled options or unknown selectors fail bootstrap; they never substitute a simulated or local sender. `disabled` sends nothing. Without a selector, Development preserves an explicitly configured local Mailpit sink; other environments are disabled. Explicit `smtp` accepts only Development and localhost/127.0.0.1/mailpit with a valid port. Hosted readiness must additionally reject disabled application email where required.

MailerSend calls its provider-owned `https://api.mailersend.com/v1/email` endpoint using one Bearer-authenticated JSON request, one recipient and text. The provider's path is external and is not a Swoovr API path/version policy. A dedicated client disables redirects and HTTP logging; it has no retry handler. The adapter owns a finite linked deadline (default15 seconds,1–60 allowed), bounds message input and streams at most8193 bytes when examining a missing acknowledgement. Tokens, addresses, bodies, provider error text and provider IDs are not logged or reflected into outcome codes.

`202` plus one bounded valid `x-message-id` means provider acceptance only. A paused acceptance remains explicitly paused. Documented `ALL_SUPPRESSED` with no message ID is rejected. Invalid/missing acknowledgement, network failure, in-flight cancellation, rate limiting and server errors are unknown; the adapter never blindly retries them. Selected client/config failures remain failures. Local pre-send cancellation has no effect and may be retried. Existing bool callers receive true only for acceptance; durable workflows must use `SendOutcomeAsync` where they distinguish uncertainty. Neither API acceptance nor the compatibility bool proves delivery/read.

The [official email contract](https://developers.mailersend.com/api/v1/email) and [general resource documentation](https://developers.mailersend.com/general) were checked31 October2026. Postman api-discovery/Orbit located the send endpoint but its saved example only showed200 with no acknowledgement semantics; primary provider docs supply the202/id/suppression contract. Tests reuse the repository's fake HTTP and actual local-browser harnesses rather than binding or publishing a Postman workspace. No real MailerSend request is part of local verification.
